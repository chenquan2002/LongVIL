# LongVIL: Video-Grounded Verification for Long-Horizon Visual Imitation Learning

This repository provides the code for LongVIL, a long-horizon visual imitation learning framework that infers temporally ordered action plans from human demonstration videos and translates the verified plans into executable robot programs.

This anonymous release contains:

- planning and code-generation agents;
- prompt templates used by the agents;
- temporal, spatial, and plan-code verification tools;
- keyframe and frame extraction utilities;
- example inputs and example outputs;
- evaluation scripts for EMA, SMS, and FSA.

Author names, affiliations, citation information, project-page links, and non-anonymous dataset or code links are intentionally omitted during anonymous peer review.

The prompts used by LongVIL are stored under `prompts/`.

| Prompt file | Purpose |

## Environment Setup

Our experiments were conducted with:

- Ubuntu 22.04.4 LTS
- Python 3.10.14
- PyTorch 2.4.0 + CUDA 12.1
- NVIDIA 4090D GPU

Create the environment from `environment.yml`:

```bash
conda env create -f environment.yml -n longvil
conda activate longvil
```

## API Configuration

LongVIL uses an OpenAI-compatible chat-completions endpoint.

Set your API key and endpoint before running inference:

```bash
export LONGVIL_API_KEY="YOUR_API_KEY"
export LONGVIL_API_BASE_URL="https://your_baseurl/v1/chat/completions"
```

The endpoint should support a GPT-4o-compatible model interface.

No real API key or private endpoint is included in this anonymous release.

## Keyframe Extraction

Before running inference, each video should be converted into frame files and keyframe metadata. The provided example data already contains these files.

For a raw video, run:

```bash
python get_frames.py \
  --video_path data/example/example1/example_clean.mp4 \
  --output_dir data/example/example1 \
  --gaussian_sigma 5 \
  --prominence 0.8
```

This creates:

```text
data/example/example1/example_clean/
├── frames/
├── hand_images/
├── selected_frames/
├── keyframelist.json
├── frames_with_hand.json
├── Left_speed_smoothed.jpg
└── Right_speed_smoothed.jpg
```

For convenience, we also provide:

```bash
bash run_get_frames.sh
```

or:

```bash
bash run_get_frames.sh data/example/example1/example_clean.mp4
```

For benchmark data, preprocess clean and complex videos separately:

```bash
bash run_get_frames.sh data/level1/<task_id>/<task_id>_clean.mp4
bash run_get_frames.sh data/level1/<task_id>/<task_id>_complex.mp4
```

## Running Inference

Run the default example:

```bash
bash run.sh
```

Equivalent explicit usage:

```bash
bash run.sh data/example/example1/example.json clean
```

For a complex video:

```bash
bash run.sh data/example/example3/example.json complex
```

For benchmark data, use the corresponding task JSON and data type:

```bash
bash run.sh data/level1/<task_id>/<task_id>.json clean
bash run.sh data/level1/<task_id>/<task_id>.json complex
```

By default, `run.sh` writes new inference results to:

```text
output_new/
```

The released repository also contains pre-generated example outputs under:

```text
output/
```

## Output Format

Each inference run produces a directory such as:

```text
output/data/example/example1/example_clean/gpt-4o-gpt-4o/
```

The main files are:

| File | Description |
|---|---|
| `Result.json` | Final generated action sequence and robot code. |
| `Planlogs.json` | Planning-agent logs. |
| `Codelogs.json` | Code-generation logs. |
| `aug_keyframelist.json` | Augmented keyframe list. |
| `runtime.json` | Runtime information. |
| `token_usage.jsonl` | Token usage records. |
| `token_usage_dict.json` | Aggregated token usage. |
| `sim.mp4` | Execution visualization. |
| `compare_results.csv` | Evaluation details for the example output. |
| `keyframes/` | Keyframes used by the agent. |

The `output/` directory is included as example output so that reviewers can inspect the expected result format without rerunning the full pipeline.

## Evaluation

We provide `evaluate.py` for evaluating generated results.

### Single-task evaluation

```bash
python evaluate.py \
  --gt_json data/example/example1/example.json \
  --pred_json output/data/example/example1/example_clean/gpt-4o-gpt-4o/Result.json \
  --save_csv results_single.csv
```

### Batch evaluation

```bash
python evaluate.py \
  --gt_root data/example \
  --pred_root output/data/example \
  --model_dir gpt-4o-gpt-4o \
  --save_csv results_batch.csv
```

For newly generated outputs from `run.sh`, replace `output/data/example` with the corresponding path under `output_new/`.

### Metrics

We report three metrics:

| Metric | Description |
|---|---|
| EMA | Exact Match Accuracy; whether the generated primitive sequence exactly matches the ground truth. |
| SMS | Step-wise Matching Score; prefix-level step matching between prediction and ground truth. |
| FSA | Final State Accuracy; whether executing the generated program reaches the target final object state. |
